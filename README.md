# Hey_Techys — October Project: Styling the Profile & Contact Hub

Welcome! This is the shared project repo for the Hey_Techys mentorship program's October track — **CSS Fundamentals (Block 3)** and **Flexbox & Responsive Design (Block 4)**.

In September you built the structure with semantic HTML. This month you make it look good: selectors, the box model, typography, positioning, Flexbox and mobile-first responsive design.

## How this repo works

- `main` is the shared branch. It only ever contains **finished, merged work**.
- Every open issue on GitHub corresponds to one small build task.
- You pick an unclaimed issue, build it on your own branch, and open a PR back into `main`.
- Once your PR is reviewed and merged, you get the points for that issue.

See `CONTRIBUTING.md` for the exact step-by-step workflow — read it before your first PR.

## Structure

```
hey-techys-october/
├── README.md
├── CONTRIBUTING.md
├── index.html                  ← hub page, links out to every challenge
├── style.css                   ← styles for the hub page
└── challenges/
    ├── block-3/                ← CSS Fundamentals challenges
    │   └── (your challenge folders go here)
    └── block-4/                ← Flexbox & Responsive Design challenges
        └── (your challenge folders go here)
```

Each challenge you build gets its **own folder** inside the issue's folder, named after you, containing an `index.html` and a `style.css`. Every issue folder also has an `example/` with a worked reference.

## Scoring

Beginner = 1 point · Intermediate = 3 points · Advanced = 6 points. Points are only counted once your PR is merged into `main`. Full rules are in the pinned Slack post and the scoring spreadsheet.

## Getting started

```bash
git clone https://github.com/Hey-Techys/CSS-TRACK.git
cd CSS-TRACK
git checkout -b issue-03-color-palette-contrast
```

Then follow `CONTRIBUTING.md`.
