# Issue #14 — Build a mobile-first landing page with Flexbox

**Tier:** Advanced (6pt)

## What to build

Build a complete single-page landing page, mobile-first: a navbar, a hero, a 3-item features section, a testimonial, and a footer — all laid out with Flexbox and adapting across two breakpoints.

## Requirements

- Mobile-first CSS with exactly two `min-width` breakpoints (e.g. 640px and 1024px) that both change the layout
- Navbar, hero (text + image side by side on desktop), features row and footer all use Flexbox
- No horizontal scroll at any width from 320px up; images are responsive
- A consistent spacing scale and max content width are used throughout (list them in a comment)
- All interactive elements have visible `:hover` and `:focus-visible` states and text meets AA contrast

## Where to put your work

```
challenges/block-4/14-responsive-landing-section/(your-name)/index.html
challenges/block-4/14-responsive-landing-section/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- The page works from 320px to desktop with two meaningful breakpoints and no overflow
- PR opened against `main`, linked to this issue (`Addresses #14`)
