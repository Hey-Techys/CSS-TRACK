# Issue #5 — Write your first mobile-first media query

**Tier:** Beginner (1pt)

## What to build

Style a page for small screens first, then use one `min-width` media query to increase font size and spacing on larger screens.

## Requirements

- Base styles (outside any media query) target small screens
- One `@media (min-width: ...)` query (e.g. 768px) increases heading size and page padding
- No `max-width` media queries — mobile-first only
- Page includes the viewport meta tag

## Where to put your work

```
challenges/block-4/05-mobile-first-media-query/(your-name)/index.html
challenges/block-4/05-mobile-first-media-query/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- Base styles are for mobile and one min-width query enhances larger screens
- PR opened against `main`, linked to this issue (`Addresses #5`)
