# Issue #6 — Make images responsive so they never overflow

**Tier:** Beginner (1pt)

## What to build

Add a large image and a small gallery to a page and make sure no image ever overflows its container on small screens.

## Requirements

- All images use `max-width: 100%` and `height: auto`
- Images use `display: block` to remove the gap underneath
- Each image has meaningful `alt` text
- At 320px wide there is no horizontal scroll

## Where to put your work

```
challenges/block-4/06-responsive-images/(your-name)/index.html
challenges/block-4/06-responsive-images/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- Images scale down with their container and never cause horizontal scroll
- PR opened against `main`, linked to this issue (`Addresses #6`)
