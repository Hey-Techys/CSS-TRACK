# Issue #4 — Build a wrapping tag list with flex-wrap

**Tier:** Beginner (1pt)

## What to build

Build a list of 8 or more skill tags (pills) that sit in a row and wrap onto new lines when they run out of space.

## Requirements

- Tags are `<li>` items in a `<ul>` with `display: flex` and `flex-wrap: wrap`
- Spacing between tags uses `gap`
- Each tag is styled as a pill (`padding`, `border-radius`, background color)
- Resizing the window makes the tags wrap — none overflow off-screen

## Where to put your work

```
challenges/block-4/04-flex-wrap-tag-list/(your-name)/index.html
challenges/block-4/04-flex-wrap-tag-list/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- Tags wrap cleanly at any width
- PR opened against `main`, linked to this issue (`Addresses #4`)
