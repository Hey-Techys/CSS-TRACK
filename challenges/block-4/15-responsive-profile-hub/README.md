# Issue #15 — Restyle your Profile & Contact Hub as a responsive site

**Tier:** Advanced (6pt)

## What to build

Take your September Profile & Contact Hub (bio, projects and contact form) and turn it into a polished, responsive site using everything from Blocks 3 and 4: typography, spacing, positioning and Flexbox.

## Requirements

- Responsive navbar, an about section with an image beside the text on desktop, a projects card row and a styled contact form
- Mobile-first with at least two `min-width` breakpoints; works with no horizontal scroll from 320px up
- Project cards are equal height with aligned links (flex column + `margin-top: auto`)
- Contact form keeps visible labels and focus states from Block 3, and meets AA contrast
- CSS is organised into commented sections (base, layout, components, media queries)

## Where to put your work

```
challenges/block-4/15-responsive-profile-hub/(your-name)/index.html
challenges/block-4/15-responsive-profile-hub/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- The hub is fully responsive, accessible and organised into commented CSS sections
- PR opened against `main`, linked to this issue (`Addresses #15`)
