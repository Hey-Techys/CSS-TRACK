# Issue #2 — Center an element horizontally and vertically with Flexbox

**Tier:** Beginner (1pt)

## What to build

Center a card in the middle of the viewport, both horizontally and vertically, using Flexbox on its parent.

## Requirements

- Parent has `display: flex`, `justify-content: center` and `align-items: center`
- Parent fills the viewport height (`min-height: 100vh`)
- No `position`, `margin-top` or `transform` hacks used for centering
- Card stays centered when the window is resized

## Where to put your work

```
challenges/block-4/02-center-with-flexbox/(your-name)/index.html
challenges/block-4/02-center-with-flexbox/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- The card stays centered at any window size using only flexbox
- PR opened against `main`, linked to this issue (`Addresses #2`)
