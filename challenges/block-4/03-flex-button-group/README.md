# Issue #3 — Build a button group with Flexbox and gap

**Tier:** Beginner (1pt)

## What to build

Build a row of 3 action buttons (e.g. Save, Preview, Cancel) laid out with Flexbox and spaced with `gap`.

## Requirements

- Buttons are real `<button>` elements inside a flex container
- Spacing uses `gap` (no margins on the buttons)
- One button is visually primary, the others secondary
- Buttons have visible `:hover` and `:focus-visible` states

## Where to put your work

```
challenges/block-4/03-flex-button-group/(your-name)/index.html
challenges/block-4/03-flex-button-group/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- Buttons are spaced with gap and have clear primary/secondary styles
- PR opened against `main`, linked to this issue (`Addresses #3`)
