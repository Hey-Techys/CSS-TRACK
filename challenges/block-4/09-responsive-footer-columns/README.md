# Issue #9 — Build a footer with columns that stack on mobile

**Tier:** Beginner (1pt)

## What to build

Build a site footer with three link columns (e.g. Program, Community, Resources) that stack on mobile and sit side by side on wider screens.

## Requirements

- Footer contains 3 columns, each with a heading and a list of links
- Columns stack on mobile (base styles) and become a flex row at a `min-width` breakpoint
- Spacing uses `gap`; list bullets and default padding removed
- Links have visible `:hover` and `:focus-visible` states and meet AA contrast

## Where to put your work

```
challenges/block-4/09-responsive-footer-columns/(your-name)/index.html
challenges/block-4/09-responsive-footer-columns/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- Footer columns stack on mobile and form a row on larger screens
- PR opened against `main`, linked to this issue (`Addresses #9`)
