# Issue #1 — Build a horizontal navbar with Flexbox

**Tier:** Beginner (1pt)

## What to build

Build a site header with a logo on the left and navigation links on the right, laid out with Flexbox.

## Requirements

- `<header>` contains a logo/site name and a `<nav>` with a `<ul>` of at least 3 links
- Header uses `display: flex`, `justify-content: space-between` and `align-items: center`
- The `<ul>` is also a flex container with `gap` between links (list bullets and default margins removed)
- Links have visible `:hover` and `:focus-visible` styles

## Where to put your work

```
challenges/block-4/01-flexbox-navbar/(your-name)/index.html
challenges/block-4/01-flexbox-navbar/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- Logo and links sit on one line, spaced with flexbox properties
- PR opened against `main`, linked to this issue (`Addresses #1`)
