# Issue #3 — Apply a 3-color palette with accessible contrast

**Tier:** Beginner (1pt)

## What to build

Pick a small color palette (a background, a text color and an accent) and apply it to a page. Check that text has enough contrast to be readable.

## Requirements

- Use at least 3 colors, written in at least two formats (e.g. hex and `rgb()` or `hsl()`)
- The accent color is used for headings or links
- Body text and its background meet WCAG AA contrast (4.5:1) — check with a contrast checker and note the ratio in a CSS comment
- No more than 5 colors used in total

## Where to put your work

```
challenges/block-3/03-color-palette-contrast/(your-name)/index.html
challenges/block-3/03-color-palette-contrast/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- Text/background contrast ratio is noted in a CSS comment and passes AA
- PR opened against `main`, linked to this issue (`Addresses #3`)
