# Issue #10 — Style your Block 1 bio page with typography and spacing

**Tier:** Intermediate (3pt)

## What to build

Take a semantic bio page (your own from Block 1, or the example markup) and give it a polished look using only typography, color and spacing — no layout tricks yet.

## Requirements

- External stylesheet with a base font stack, text color and background color
- Content is centered with `max-width` and `margin: 0 auto`, and has readable line length (around 60–75 characters)
- Consistent spacing: margins/padding use a small set of rem values (e.g. 0.5rem, 1rem, 2rem)
- `header`, `main` and `footer` are visually distinct (e.g. background color, border or spacing)

## Where to put your work

```
challenges/block-3/10-style-bio-page/(your-name)/index.html
challenges/block-3/10-style-bio-page/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- The page is readable and consistently spaced using only typography, color and spacing
- PR opened against `main`, linked to this issue (`Addresses #10`)
