# Issue #12 — Style a contact form with clear labels, spacing and focus states

**Tier:** Intermediate (3pt)

## What to build

Style an accessible contact form (from Block 2 or the example markup) so it's easy to read and use: stacked labels, comfortable spacing, consistent input sizes and an obvious focus state.

## Requirements

- Labels sit above their inputs (`display: block`) with consistent spacing between fields
- Inputs, textarea and button share the same `font-family` and `font-size` as the page (`font: inherit`)
- Inputs have a visible border and a clearly different `:focus-visible` style (the outline is never removed)
- Text and borders meet AA contrast (4.5:1 for text, 3:1 for input borders)

## Where to put your work

```
challenges/block-3/12-style-accessible-form/(your-name)/index.html
challenges/block-3/12-style-accessible-form/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- The form is readable, consistently spaced and has a clear keyboard focus state
- PR opened against `main`, linked to this issue (`Addresses #12`)
