# Issue #2 — Set a typography scale for headings and paragraphs using rem

**Tier:** Beginner (1pt)

## What to build

Style `h1`, `h2`, `h3` and `p` so they form a clear size hierarchy. Use `rem` units so text scales with the user's browser font-size setting.

## Requirements

- `html` or `body` sets a base `font-size` (or leaves the browser default of 16px)
- `h1`, `h2`, `h3` and `p` each have a `font-size` in `rem`, getting smaller in order
- Headings and paragraphs each set a `line-height` (unitless, e.g. `1.2` / `1.6`)
- No `px` values for font sizes
