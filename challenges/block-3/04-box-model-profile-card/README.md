# Issue #4 — Style a profile card using the box model

**Tier:** Beginner (1pt)

## What to build

Build a small profile card (name, role, short bio) and style it using `padding`, `border` and `margin`. Use `box-sizing: border-box` so the card's width includes its padding and border.

## Requirements

- Card is an element with a class (e.g. `.card`) containing a name, role and short bio
- Card has a fixed `width` (or `max-width`), plus `padding`, `border` and `margin`
- `box-sizing: border-box` is applied (to the card or globally with `*`)
- Card uses `border-radius` for rounded corners

## Where to put your work

```
challenges/block-3/04-box-model-profile-card/(your-name)/index.html
challenges/block-3/04-box-model-profile-card/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- Card spacing is built only from padding, border and margin
- PR opened against `main`, linked to this issue (`Addresses #4`)
