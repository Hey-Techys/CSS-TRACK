# Issue #5 — Style a list using element, class and ID selectors

**Tier:** Beginner (1pt)

## What to build

Build a short list of your favourite tools and style it using all three basic selector types: an element selector, a class selector and an ID selector.

## Requirements

- An element selector styles every `li`
- A class selector (e.g. `.highlight`) styles two or more items differently
- An ID selector (e.g. `#favourite`) styles exactly one item
- A CSS comment above each rule says which selector type it is

## Where to put your work

```
challenges/block-3/05-element-class-id-selectors/(your-name)/index.html
challenges/block-3/05-element-class-id-selectors/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- All three selector types are used and labeled with comments
- PR opened against `main`, linked to this issue (`Addresses #5`)
