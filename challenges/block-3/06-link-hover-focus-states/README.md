# Issue #6 — Style links with hover, focus and visited states

**Tier:** Beginner (1pt)

## What to build

Style a set of links so they look different in each state: default, `:visited`, `:hover`, `:focus-visible` and `:active`.

## Requirements

- Rules for `a`, `a:visited`, `a:hover`, `a:focus-visible` and `a:active`, in that order
- Hover and focus styles are clearly visible (not color alone — e.g. underline or outline change)
- The focus outline is never removed (`outline: none` is not allowed)
- At least 3 links on the page

## Where to put your work

```
challenges/block-3/06-link-hover-focus-states/(your-name)/index.html
challenges/block-3/06-link-hover-focus-states/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- Every link state is visibly different, including keyboard focus
- PR opened against `main`, linked to this issue (`Addresses #6`)
