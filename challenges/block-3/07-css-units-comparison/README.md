# Issue #7 — Compare px, %, em and rem units side by side

**Tier:** Beginner (1pt)

## What to build

Build a small page with four boxes, each sized with a different unit (`px`, `%`, `em`, `rem`). Add a short note in each box explaining what its unit is relative to.

## Requirements

- Four boxes, one each for `px`, `%`, `em` and `rem`
- Each box's `width` or `padding` uses its unit
- The `em` box sits inside a parent with a different `font-size`, so the difference from `rem` is visible
- Each box contains a one-sentence explanation of its unit

## Where to put your work

```
challenges/block-3/07-css-units-comparison/(your-name)/index.html
challenges/block-3/07-css-units-comparison/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- All four units are used and explained on the page
- PR opened against `main`, linked to this issue (`Addresses #7`)
