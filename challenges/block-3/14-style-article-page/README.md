# Issue #14 — Build a fully styled, readable article page

**Tier:** Advanced (6pt)

## What to build

Style a long-form article page (from Block 1 or your own) to professional reading quality: comfortable measure, vertical rhythm, a consistent spacing scale and styled supporting elements.

## Requirements

- Content width limited with `max-width` in `ch` (around 60–75ch) and centered
- A spacing scale of 3–5 rem values is used consistently for all margins and padding (list it in a comment at the top of the CSS)
- Styled `blockquote`, inline `code`, `figure`/`figcaption` and lists — each visually distinct but consistent with the page
- Heading sizes use rem, body `line-height` is between 1.5 and 1.8, and all text meets AA contrast
- No layout tools beyond the box model and normal flow (no flexbox/grid yet)

## Where to put your work

```
challenges/block-3/14-style-article-page/(your-name)/index.html
challenges/block-3/14-style-article-page/(your-name)/style.css
```

## Definition of done

- Builds and displays correctly in a browser
- The article is comfortable to read and every spacing value comes from the declared scale
- PR opened against `main`, linked to this issue (`Addresses #14`)
