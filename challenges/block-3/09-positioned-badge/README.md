# Issue #9 — Position a badge on a card with relative and absolute positioning

**Tier:** Beginner (1pt)

## What to build

Add a small "New" badge to the top-right corner of a card. The card uses `position: relative` and the badge uses `position: absolute` so it stays pinned to the card's corner.

## Requirements

- Card has `position: relative`
- Badge has `position: absolute` with `top` and `right` values
- Badge stays in the card's corner when the card moves or resizes
- A CSS comment explains why the parent needs `position: relative`
